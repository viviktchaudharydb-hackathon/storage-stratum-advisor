# Bank Storage Standards & Procurement Policy (excerpt)

1. Preferred vendors with active agreements (NetApp, Dell, GCP) must be
   evaluated first; deviations require Architecture Review Board approval.
2. All production storage must meet 99.99% availability minimum; Tier-1
   (payments, core banking) requires 99.999% with synchronous replication.
3. New vendors require security assessment (8–12 weeks) and RBI outsourcing
   compliance review before PO issuance.
4. Cloud storage for regulated data must remain in-region (asia-south1 /
   asia-south2) with CMEK encryption.
5. TCO evaluations must use 3-year horizon including support, power/cooling
   (on-prem at $180/TB/3yr), and migration costs.
